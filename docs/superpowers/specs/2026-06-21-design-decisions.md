- `ellipse 60% 70% at 80% 60%, rgba(94,120,191,0.03) → transparent`

浅色模式：`#f3f4f6` 底，无需纹理或极淡

## 3. 组件规范

### 3.1 窗口外壳（Double Bezel）

所有浮动窗口使用双层嵌套：
- 外层：渐变色边框环 + 大投影
- 内层：背景 + `backdrop-filter: blur(40px) saturate(140%)` + `inset 0 1px 0 highlight`

### 3.2 卡片（Card Wrap）

便签/剪切板/邮件卡片统一使用：
- 外层 `card-wrap`：透明背景，hover 时渐现 accent 渐变边框
- 内层 `card`：`bg-card` + `border: 1px solid --border` + `inset 0 1px 0 highlight`
- 固定项 pinned：外层常驻 accent 渐变背景
- 已完成：`opacity: 0.52` + `text-decoration: line-through` 标题
- 新邮件未读：左侧 2px accent 色条

### 3.3 Tab 导航栏

- 浮动 pill 形态：`bg-card` 背景 + `border: 1px solid --border` + `border-radius: 9999px`
- 内部 padding 3px，按钮间距 2px
- 选中态：`::before` 伪元素 accent 辉光背景 + 细边框，内缩 2px
- Tab 图标：SVG 几何图标，1.5px 笔画，15px 尺寸
- Tab 文字：11px / 500（未选中）、600（选中）

### 3.4 图标

- 全部使用 **SVG sprite**（内联 symbol），1.5px 细笔画
- 不使用 emoji（原 demo 中已全部替换）
- 不使用 Lucide/FontAwesome 等第三方图标库
- 图标集：search、plus、minus、x、check、pin、trash、clipboard、mail、notes、settings、refresh、power、arrow-right、lock、picture、file、link、circle

### 3.5 按钮

| 类型 | 样式 |
|------|------|
| 图标按钮 | 30x30、`border-radius: 8px`、`bg-card` |
| 主操作按钮 | `border-radius: 9999px`（pill）、`bg: accent`、`color: #0d1a16`（深色）/ `#fff`（浅色） |
| 迷你按钮 | 24x24、`border-radius: 6px`、透明背景、hover 显示 |
| 危险按钮 | `color: --danger`、透明背景 |

主按钮使用 "按钮内嵌套箭头" 模式：右侧有一个圆形 `bg: rgba(0,0,0,0.10)` 包裹的箭头图标，hover 时箭头右移。

### 3.6 输入框

- 36px 高度、8px 圆角、`bg-input` 背景
- border: 1px solid `--border`
- focus：`border-color: accent 40%` + `box-shadow: 0 0 0 3px accent-dim`
- placeholder：`--text-tertiary`

## 5. 约束规则

> **后续讨论和实现中，以下规则必须遵守。违反时自动提醒。**

| 规则 | 说明 |
|------|------|
| 🔒 图标 | 只用 SVG sprite，禁用 emoji 和第三方图标库 |
| 🔒 圆角 | 严格使用令牌值（20/14/12/8/6/full），不随意创建新值 |
| 🔒 颜色 | 只用令牌色，不引入新颜色除非讨论确认 |
| 🔒 动效 | 只用已定义的 cubic-bezier 曲线 |
| 🔒 卡片 | 任何列表项必须使用 double-bezel card-wrap + card 结构 |
| 🔒 间距 | 窗口内 padding 统一为 12px（横）/ 16px（header） |
| 🔒 按钮文案 | 不超过 4 个字 |
